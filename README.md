# 💰 SmartSpend AI

SmartSpend AI is a full-stack expense tracking and analytics platform developed using Flask, SQLite, JavaScript, and Chart.js. The application helps users manage personal finances with interactive dashboards, expense tracking, analytics, and PDF report generation.

---

## 🚀 Features

* User Authentication (Login & Signup)
* Add and Delete Expenses
* Expense Analytics Dashboard
* Interactive Pie Chart Visualization
* Smart Spending Insights
* PDF Report Generation
* Multi-user Expense Tracking
* Responsive Fintech-style UI

---

## 🛠️ Technologies Used

### Frontend

* HTML
* CSS
* JavaScript
* Chart.js

### Backend

* Flask
* SQLite
* Flask-CORS

---

## 📊 Functionalities

* Users can create accounts and login securely
* Expenses are stored separately for each user
* Dashboard displays total spending and category analytics
* Pie charts visualize spending patterns
* PDF reports can be downloaded for expense summaries
* Smart insights help users understand spending behavior
